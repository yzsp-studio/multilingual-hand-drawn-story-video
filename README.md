## 🇨🇳 中文

这个技能在 Design 里把多语言故事或一组有序图片做成手绘故事视频。它会识别原文语言、文字系统与书写方向，不自动翻译；只挑选字符覆盖经过验证的字体，并按语言处理文字塑形、断行与阅读时长，保证画面停留跟得上读速。支持 20 种手绘风格与自定义画幅，图片和视频清晰度可分别选择，成本和画质分开控制。适合日记漫画动画、线稿上色和翻书故事视频，不用于单张插画或真人实拍视频。流程从读取项目与能力开始，拆故事、锁风格、选图片规格、写视频提示词，最后在 Design 合成。

### ✨ 能做什么

- 识别原文语言、文字系统与书写方向 → 不乱翻、不乱断行
- 只选字符覆盖经过验证的字体，按语言做文字塑形与断行
- 按语言计算阅读时长，画面停留跟得上读速
- 20 种手绘风格任选，画幅可自定义
- 图片清晰度与视频清晰度独立选择，成本与画质分开控
- 线稿上色 → 日记漫画动画 / 翻书故事视频成片

## 🇬🇧 English

This skill turns a multilingual story or an ordered set of images into a hand-drawn story video inside Design. It detects the source language, script, and writing direction and does not auto-translate; it only picks fonts whose character coverage has been verified, then handles shaping, line breaking, and reading duration per language so each frame stays on screen long enough to read. It supports 20 hand-drawn styles, custom aspect ratios, and independent image and video resolution choices, keeping cost separate from quality. It fits diary comic animation, line-art coloring, and flipbook story videos—not single illustrations or live-action footage. The flow reads the project and capabilities, splits the story, locks style, chooses image specs, writes video prompts, and composites in Design.

### ✨ What it does

- Detects source language, script, and writing direction so nothing gets mistranslated or mis-broken
- Uses only fonts with verified character coverage, with per-language shaping and line breaking
- Computes reading duration per language so frames stay long enough to read
- 20 hand-drawn styles to choose from, with custom aspect ratios
- Independent image and video resolution settings keep cost and quality separate
- Turns line art into colored diary-comic animation or flipbook story video
